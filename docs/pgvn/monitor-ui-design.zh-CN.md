# 监控页面设计约定

面向 SVN/数据库运维人员，使用紧凑、清楚的中文界面。以概览、节点、仓库、数据库和请求错误五个视图组织只读状态。桌面侧栏在窄屏改为可换行的顶部导航，不将关键表格压成不可读的列。

参考 ui-ux-pro-max 的 Minimalism & Swiss Style 和 Web 上下文状态更新建议；产品是运维控制台，因此不采用检索结果中的营销页面、试用 CTA 或外部字体。运行时不依赖 UI 框架、图标包、CDN 或在线资源。

- 中性浅色背景、深色导航、蓝色操作按钮；绿/黄/红状态同时带文字。
- 使用系统中文字体；数字使用等宽字体。正文与状态文字保持足够对比度。
- 页面顶部始终展示实例、采样时间、新鲜度和当前连接状态。null 显示为“未知”，不显示为 0。
- 令牌表单有明确标签，允许粘贴；令牌只存在当前标签页内存，提交后清空输入，不写 localStorage、sessionStorage 或 URL。
- 默认五秒刷新，请求不重叠；后台标签降频，并提供暂停和手动刷新。趋势图附带可展开的数据表，空趋势不绘制假数据。
- 单一 status 区域播报连接/认证状态变化，自动刷新不抢焦点；所有按钮和导航可用键盘操作，焦点清楚可见。
- 加载、空集、断连、过期、认证失效和服务未就绪各有明确状态。列表支持分页，刷新导致游标过期时回到第一页。
- 外部文本通过 textContent 插入，不作为 HTML。CSS/JS 使用独立同源内嵌资源和严格 CSP。

本文件描述 M4 的设计目标，完成状态以里程碑门禁及证据为准。
